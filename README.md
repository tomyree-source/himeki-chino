# 姫木整体療術茅野店 公式サイト 共同管理パッケージ

亜里奈さんが自分のClaude（AIアシスタント）で公式サイトを変更できるようにするための、引き継ぎ一式です。

## サイトの場所

- 公開中の公式サイト： https://tomyree-source.github.io/sites/himeki-chino/
- このフォルダの `site/index.html` が、公開中の最新版そのものです（2026年11月27日時点）。
- `site/sitemap.xml` は検索エンジン向けの案内ファイルです。通常は触りません。

## 共同管理の考え方

- サイトの置き場所（GitHub）は今までどおり222工房側で持ち、亜里奈さんのアカウントを共同管理者として招待します。
- 変更作業は亜里奈さんのClaudeが行い、困ったときは222工房側でもすぐ直せる形にします。
- 変更履歴はGitHubに全部残るので、間違えても前の版に戻せます。

## 亜里奈さんに用意していただくもの

1. GitHubアカウント（無料で作れます。ユーザー名を222工房へ教えてください。招待を送ります）
2. Claudeのアカウント（変更作業をさせるため。無料版は作業量の上限が低めです）

## 変更の頼み方（例）

自分のClaudeに、ふだんの言葉で頼むだけです。

- 「トップのお知らせに『12月30日〜1月3日は年末年始のお休みです』を足して、公開までやって」
- 「料金表の整顔操法の説明を、○○という文に変えて」
- 写真を変えたいときは、使いたい写真をClaudeに渡して「この写真に差し替えて」と伝えます。

同封の `MANUAL_FOR_MUSE.md` は、亜里奈さんのClaudeに最初に読ませるための作業マニュアルです。Claudeに「このマニュアルを読んで、その通りに作業して」と伝えてください。

## 大事な約束ごと

- 料金・営業時間・定休日・住所・電話番号などの事実は、お店の決めた内容のときだけ変えます。
- 「必ず良くなる」「治る」といった効能を断定する表現は書きません。
- 公開したら、必ず実際のページを開いて変わっているか確認します。

## 困ったとき

サイトが表示されない、変になってしまった等は、222工房へ連絡してください。履歴から元に戻せます。
